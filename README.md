# Luna Founder — GitHub Pages Site

Upload all files in this folder to your GitHub Pages repository and commit the changes.

## Stripe
This static site uses a Stripe Payment Link for the $9.99 Premium purchase.
Open `stripe-config.js` and replace `PASTE_YOUR_STRIPE_PAYMENT_LINK_HERE` with the Stripe Payment Link from your Stripe Dashboard.
GitHub Pages cannot run a private server-side Stripe secret key, so never put a Stripe secret key in this repository.

General is free. Premium is $9.99.


Earnings tracker: local test activity is stored in the browser. It does not hold real money or payment credentials. No Stripe connection button is included.
