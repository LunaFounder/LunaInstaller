# Luna Premium website — no Stripe yet

This is a temporary download site for Luna Premium.

- Publisher shown as: Luna Founder
- Wake phrase in the included Luna build: Hey Luna AI
- The newest Luna ZIP is `downloads/Luna.zip`
- Customers can download it from `/download/luna`

To publish a newer Luna version, replace `downloads/Luna.zip` with the latest ZIP and restart the server if needed.

Start:

```bash
npm install
npm start
```

Default: http://localhost:4242
